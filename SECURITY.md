# Security and Sensitive Disclosure

Report software vulnerabilities through GitHub private vulnerability reporting when enabled. Do not put credentials, restricted data, personally identifiable health information, culturally sensitive material, or unpublished source terms in a public issue.

Data-rights, Māori data sovereignty, privacy and legal-authority concerns are treated as release blockers even when they are not conventional software vulnerabilities.

## Supported Versions
v1.0 and above.

## Vulnerability Response
Target response within 72 hours.
