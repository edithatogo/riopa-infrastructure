# Track: Independent validation, releases and publication programme

Track ID: `publication_validation_20260718`  
Phase: **Publication**

## Goal

Convert infrastructure, data and applied work into independently validated, citable software/data releases and manuscripts.

## Dependencies

- `repository_template_adoption_20260718`
- `nz_spatial_archive_mvp_20260718`

## Scope

- Independent reproduction and audit protocol.
- Schema/profile and software releases.
- Data descriptor and applied-study publication packages.
- Citation metrics and contribution tracking.
- Long-term preservation and deprecation policy.

## Out of scope

- Publishing before rights/governance or reproducibility gates pass.
- One DOI for continuously mutable data without version clarity.

## Acceptance criteria

- [ ] At least one external/clean-room reproduction report is published.
- [ ] Code/profile and data snapshots have independent versions and persistent identifiers.
- [ ] Methods and supplementary artifacts are generated and reviewed against the evidence.
- [ ] Release correction/deprecation process is tested.
- [ ] Publication packages clearly state contributions, limitations and AI-tool use.

## Risks

- Publication incentives outrun infrastructure quality.
- Citation fragmentation.
- Long-term mirror drift.
