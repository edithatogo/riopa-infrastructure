# Stable-v1 readiness plan (2026-08-29)

This is a preparation record for the bounded regional, public-datasets-only,
non-operational technical preview. It binds to the protected-main revision in
the JSON record and deliberately leaves promotion disabled.

## Recommendation

Continue the isolated `26bc0b4` beta/RC campaign. Keep GitHub Actions as the
primary hosted evidence plane and retain Hugging Face or an institutional
repository as a secondary preservation target. Use content-bound agent panels
to qualify repository evidence, while preserving factual external-participant,
elapsed-time, provider-acceptance and owner-authority requirements.

## Remaining gates

All 14 stable gate families remain pending in the machine-readable record.
The immediate campaign requirements are 90 consecutive days and three
operational cycles for beta, and 30 consecutive days for the exact RC candidate.
Any qualifying interruption or revision change resets the affected clock.
National-scale measurements, accepted preservation, two isolated clean-room
reproductions, external operator/user workflows and the owner's signed,
tier-specific decision remain non-substitutable.

## Contingencies

- If hosted observations fail, preserve the failed receipt, classify the event,
  and reset only the affected campaign segment.
- If the candidate must change, start a new exact-candidate RC epoch and retain
  the prior segment as historical evidence only.
- If the preferred preservation target is unavailable, use the documented
  secondary target and record its acceptance receipt; do not claim preservation
  from an upload attempt.
- If external participation is unavailable, remain in technical-preview status;
  agent-panel reports may assess but cannot manufacture participant facts.

The owner release decision remains a future gate and must specify scope,
exclusions, expiry, rollback and revocation conditions.
