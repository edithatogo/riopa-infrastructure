# Maximal lawful archive default

This successor decision makes the repository's preservation posture less
restrictive while retaining a lawful basis for public copying. It supplements
the source-by-source decisions in
[`source-rights-publication-decision-matrix-20260829.md`](source-rights-publication-decision-matrix-20260829.md).

## Defaults

| Action | Default | Exclude or narrow only when |
|---|---|---|
| Acquire from a public source | Capture the complete dataset when a public download interface, source terms, owner permission or law affirmatively authorises acquisition. | Acquisition is prohibited, requires circumvention, or has no affirmative basis. |
| Preserve privately | Retain every complete lawfully acquired dataset with fixity and provenance. | An explicit retention restriction, law, privacy, safety or storage constraint prohibits it. |
| Publish evidence | Publish metadata, public URLs, terms observations, receipts, checksums, schemas, non-reconstructive statistics and decisions. | The evidence is itself expressly restricted or sensitive. |
| Publish full payload publicly | Publish whenever an affirmative publication basis is recorded. | Copying or public issue is explicitly prohibited, or no affirmative basis has yet been found. |

An affirmative public-payload basis can be an exact-item open licence, an
applicable publisher-wide licence without an item exception, recorded owner
permission, public-domain or no-known-rights status, or a documented statutory
permission applying to the exact publication.

## Why silence is not treated as permission

New Zealand copyright arises automatically. Section 16 of the Copyright Act
1994 reserves copying and issuing copies to the public to the copyright owner,
and IPONZ says that copying or uploading another person's protected work
generally requires permission. Consequently, “the source does not say no” is
not itself a lawful public-republication licence.

This does not justify discarding or hiding a source. A missing redistribution
licence does not undo a separate lawful acquisition basis. After lawful
acquisition it blocks only public payload bytes, not full private preservation
or publication of unrestricted evidence. A takedown process supplements a
valid publication basis; it does not create one.

## Contingencies

- Split mixed-rights packages so open components remain public.
- If terms change, quarantine only affected payloads and issue a successor
  decision; retain the historical decision trail where lawful.
- If a rights claim is challenged, temporarily restrict the affected payload,
  investigate provenance and restore access if its publication basis survives.
- Record technical or storage deferrals as resumable capture plans rather than
  rights exclusions.

This is the most permissive default the repository can apply without equating
copyright silence with permission.
