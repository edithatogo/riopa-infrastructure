# v0.2.0 technical-preview support policy

## Supported surface

For twelve calendar months from GitHub publication, the project supports the
released M1 roadmap, maturity/release configuration, roadmap validator,
issue-graph generator and example research-object build at the exact `v0.2.0`
tag. Support means triaging reproducible defects, publishing material
corrections and maintaining an auditable withdrawal route.

This policy does not convert experimental interfaces into stable contracts and
does not extend to the later platform, data, analytics or application tracks.
Those tracks continue under their own 0.3.0-1.0.0 specifications.

## Environments and requests

The release workflow's locked Python environment is the reference environment.
A support report should include the tag, operating system, architecture, Python
version, exact command, exit status and any relevant digest. Reports use the
repository security policy for vulnerabilities and GitHub issues for ordinary
defects.

## Response boundaries

- Integrity, security and inability-to-verify reports receive priority triage.
- Compatibility help is best effort because this is a technical preview.
- No service-level response time, uptime, data freshness, national coverage or
  operational outcome is promised.
- External reproduction and user/operator evidence are factual later gates;
  support interactions do not automatically satisfy them.

## Corrections, withdrawal and end of support

Material defects receive a linked correction, superseding release or withdrawal
notice. Published tags and provenance records remain available when safe so the
history stays auditable; compromised assets are clearly marked and removed from
recommended use.

The support window starts at the GitHub release publication timestamp,
`2026-08-25T15:27:39Z`, and ends at `2027-08-25T15:27:39Z`. At end of support
the project will either announce an extension, point to a supported successor,
or archive the preview as unsupported.

This support window does not delay or cancel later Conductor tracks.
