# Accessibility contract v1

The versioned travel-matrix and measure schemas define explicit engine, mode,
source and parameter identities. `reachable`, `unreachable`, `missing` and
`censored` observations are distinct; only reachable observations may carry a
non-negative impedance. Measures declare missing-value and denominator
semantics.

The contract is reference-only. It does not assert that a road, walk, cycle or
public-transport archive exists and does not enable network, timetable,
facility, national, operational or authoritative claims.
