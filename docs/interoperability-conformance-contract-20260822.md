# Bounded interoperability conformance contract

The contract binds the existing language-neutral corpus to its Python and Node
runners and records conservative profile/version negotiation. Positive and
negative cases are required; migration cases remain a planned extension until
an exercised migration fixture exists. Unknown extensions are preserved and
declared, while a major profile change is breaking.

This is repository-owned contract evidence only. It does not claim complete
JSON Schema support, Rust or SHACL parity, standards round trips, external
producer/consumer qualification, signed reports, or release authority.
