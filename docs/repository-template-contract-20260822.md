# Repository-template contract (single-developer, additive)

`docs/repository-template-contract-20260822.json` defines the safe boundary
for greenfield setup and brownfield adoption. It identifies the required
governance/CI/release scaffolding, generated versus hand-authored files, and
the self-tests that a candidate repository must run. Brownfield adoption is
additive: existing history, raw evidence and local customisation are not
overwritten.

The contract is a repository-owned preparation artifact. It does not assert
that any related repository has adopted RIOPA, passed independent reproduction,
or satisfied external-user or release gates.
