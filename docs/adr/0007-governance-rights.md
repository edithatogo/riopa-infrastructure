# ADR-0007: Rights and Māori Data Sovereignty as Core Metadata

- **Status:** Accepted for v0.1
- **Date:** 2026-07-18

## Context

Open technical access is not equivalent to permission, social licence or legitimate governance. Spatial and health analyses can affect Māori communities even when inputs are aggregate and public.

## Decision

Rights, attribution, redistribution status and governance assessments are mandatory first-class records. Data for, from or about Māori triggers Māori data sovereignty review. Public release fails closed when redistribution status is unresolved.

## Consequences

- Some materialisations may be local-only or metadata-only.
- Governance evidence is part of the research object.
- Source rights cannot be homogenised into the repository code licence.
