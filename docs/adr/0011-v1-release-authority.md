# ADR-0011: Evidence-Based v1 Release Authority

- **Status:** Proposed for v0.2 ratification
- **Date:** 2026-07-19

## Context

Feature completion and paper readiness create pressure to declare stability before compatibility, governance, security and operations are proven.

## Decision

Use the M0–M6 maturity model and a recorded cross-functional release authority. v1.0 requires all machine-readable gates, an RC soak period, independent reproduction, named maintainers and zero critical blockers. Governance prohibitions and release-integrity failures cannot be waived.

## Consequences

The programme may remain at v0.9 until evidence is complete. The GA decision and sign-offs are preserved as part of the release object.
