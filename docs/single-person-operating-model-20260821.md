# Single-person operating model

RIOPA Infrastructure is owned and operated by one person: the repository
owner. There is no second maintainer, human reviewer, external operator, or
external user in the operating model.

Agents may execute operator and user workflow scripts, run clean-room
reproductions, and form an agent-panel qualification report. These are
owner-authorized agent observations, not independent human review and not a
fabricated third-party receipt.

The repository owner is the accountable release authority for every tier. An
agent may prepare a digest-bound decision record, but promotion still requires
the owner's explicit tier decision containing scope, exclusions, expiry,
rollback and revocation conditions.

The approved product boundary remains a bounded regional, public-datasets-only,
non-operational technical preview. Network, timetable, facility, national,
clinical, dispatch and authoritative claims remain disabled until separately
evidenced.
